MicroAutograd Engine Details

MicroAutograd: Reverse-Mode Differentiation

Goal: Implement automatic differentiation and backpropagation from scratch in Python to thoroughly understand computational graphs without black-box abstractions.

Core Mechanisms:

1. Value Node: Every scalar value is an instance of Value(data, _children, _op) holding its numerical value and its accumulated gradient (grad).

2. DAG Construction: Overloaded arithmetic operators (+, *, pow, tanh, relu) automatically record parents and local derivative closures.

3. Topological Sort: Backpropagation traverses the computation DAG in reverse topological order, recursively applying the chain rule: child.grad += local_deriv * parent.grad.

4. MLP Training: Trains a multi-layer perceptron with arbitrary hidden layers on binary classification datasets.
