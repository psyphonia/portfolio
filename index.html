LeetCode Coach Details

LeetCode Coach | Hugging Face Spaces

Status: Personal Project (2026) • Deployed

Technologies: Python, Hugging Face Spaces, Git

Overview:

Built and deployed an AI-powered coding coach designed to help programmers work through challenging algorithmic problems on LeetCode.

Key Capabilities:

• Progressive Hints: Instead of immediately revealing full solutions, provides step-by-step Socratic hints to guide the user's own deduction.

• Debugging Guidance: Analyzes user-submitted attempts, identifies logical bugs, edge cases, and off-by-one errors.

• Pattern Recognition & Complexity: Identifies the underlying Data Structures & Algorithms pattern (e.g., Two Pointers, Sliding Window, Dynamic Programming, Topological Sort) and provides an estimate of time/space complexity.

Pigeon-Feeding Hotspot CV

Pigeon-Feeding Hotspot Detection | Computer Vision

Status: Ongoing Project • In Development

Domain: Computer Vision, Public Health, Environmental AI

Problem & Motivation:

Uncontrolled pigeon feeding in urban centers leads to acute localized overpopulation, creating public health concerns such as hypersensitivity pneumonitis and other chronic respiratory risks associated with droppings.

Technical Implementation:

• Building a computer vision pipeline to analyze road and roadside surveillance streams.

• Detects vehicles slowing down and stopping near known feeding spots.

• Leverages temporal stopping patterns and vehicle dwell times to automatically flag hotspots with concentrated, repeated feeding, providing actionable data for municipal mitigation efforts.
